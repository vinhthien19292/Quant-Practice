1. The idea of a limit

Consider the function \(f(x) = \dfrac{x^2 - 1}{x - 1}\). At \(x = 1\), the formula gives \(0/0\), which is undefined. But if we compute \(f\) at values near \(1\):

x0.90.990.9991.0011.011.1
\(f(x)\)1.91.991.9992.0012.012.1

The values approach \(2\) from both sides. We say the limit of \(f(x)\) as \(x\) approaches \(1\) is \(2\), even though \(f(1)\) itself is not defined. Algebraically, \(\dfrac{x^2-1}{x-1} = \dfrac{(x-1)(x+1)}{x-1} = x+1\) for \(x \neq 1\), which explains why the limit equals \(1 + 1 = 2\).

Definition 1.1 — Limit (informal)

We say \(\lim_{x \to a} f(x) = L\) if the values of \(f(x)\) get arbitrarily close to \(L\) whenever \(x\) is sufficiently close to (but not equal to) \(a\).

The value \(f(a)\) itself need not exist, nor equal \(L\) if it does.

Notation: \(\lim_{x \to a} f(x) = L\) or \(f(x) \to L\) as \(x \to a\).

One-sided limits

Sometimes \(f\) behaves differently as \(x\) approaches \(a\) from the left versus the right. We write:

  • \(\lim_{x \to a^-} f(x) = L\): the left-hand limit, considering only \(x < a\).
  • \(\lim_{x \to a^+} f(x) = L\): the right-hand limit, considering only \(x > a\).
Theorem 1.2 — Two-sided limit exists iff both one-sided limits exist and agree

\(\lim_{x \to a} f(x) = L\) if and only if \(\lim_{x \to a^-} f(x) = L\) and \(\lim_{x \to a^+} f(x) = L\).

Example — sign function

Let \(\text{sgn}(x) = 1\) if \(x > 0\), \(-1\) if \(x < 0\), \(0\) if \(x = 0\). Then

\(\lim_{x \to 0^+} \text{sgn}(x) = 1\) and \(\lim_{x \to 0^-} \text{sgn}(x) = -1\).

Since the two disagree, \(\lim_{x \to 0} \text{sgn}(x)\) does not exist.

2. The ε-δ definition

The informal definition ("arbitrarily close", "sufficiently close") is intuitive but not rigorous. To prove theorems and handle subtle cases, we need a precise formulation.

Definition 2.1 — Limit (formal, ε-δ)

Let \(f\) be defined on an open interval containing \(a\), except possibly at \(a\) itself. We say

\[ \lim_{x \to a} f(x) = L \]

if for every \(\varepsilon > 0\), there exists \(\delta > 0\) such that

\[ 0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon. \]

Read carefully: \(\varepsilon\) represents "how close to \(L\) we want the output"; \(\delta\) represents "how close to \(a\) the input must be". The challenger picks \(\varepsilon\); we must produce a \(\delta\) that works.

Why "\(0 < |x - a|\)"?

The condition \(|x - a| > 0\) says \(x \neq a\). The limit describes behavior near \(a\), not at \(a\). Whatever \(f(a)\) is (or isn't) does not affect the limit.

Example 2.1 — proving a limit with ε-δ

Claim. \(\lim_{x \to 3} (2x + 1) = 7\).

Proof. Given \(\varepsilon > 0\), we must find \(\delta > 0\) such that \(0 < |x - 3| < \delta \implies |(2x+1) - 7| < \varepsilon\).

1Simplify \(|f(x) - L|\): \(|(2x+1) - 7| = |2x - 6| = 2|x - 3|\).
2We want \(2|x - 3| < \varepsilon\), i.e., \(|x - 3| < \varepsilon/2\).
3Choose \(\delta = \varepsilon/2\).
4Verify: if \(0 < |x - 3| < \delta = \varepsilon/2\), then \(|(2x+1) - 7| = 2|x-3| < 2 \cdot \varepsilon/2 = \varepsilon\). \(\blacksquare\)

The pattern: (1) simplify \(|f(x) - L|\) in terms of \(|x - a|\), (2) determine what \(\delta\) makes the resulting expression less than \(\varepsilon\).

Theorem 2.2 — Uniqueness of limit

If \(\lim_{x \to a} f(x) = L_1\) and \(\lim_{x \to a} f(x) = L_2\), then \(L_1 = L_2\).

Proof

Suppose \(L_1 \neq L_2\). Let \(\varepsilon = |L_1 - L_2|/3 > 0\). By hypothesis, there exist \(\delta_1, \delta_2 > 0\) such that:

\(|x - a| < \delta_1 \implies |f(x) - L_1| < \varepsilon\), and \(|x - a| < \delta_2 \implies |f(x) - L_2| < \varepsilon\).

Choose \(\delta = \min(\delta_1, \delta_2)\) and pick any \(x\) with \(0 < |x-a| < \delta\). By triangle inequality:

\[ |L_1 - L_2| \leq |L_1 - f(x)| + |f(x) - L_2| < \varepsilon + \varepsilon = \tfrac{2}{3}|L_1 - L_2|. \]

This gives \(|L_1 - L_2| < \tfrac{2}{3}|L_1 - L_2|\), impossible unless \(L_1 = L_2\). \(\blacksquare\)

Deeper dive — Cauchy sequences and completeness of ℝ

The ε-δ definition compares \(f(x)\) to a known target \(L\). But how do we know the target exists in the first place? This is where Cauchy sequences and the completeness of \(\mathbb{R}\) enter.

Definition (Cauchy sequence). A sequence \((x_n)\) is Cauchy if for every \(\varepsilon > 0\), there exists \(N\) such that \(m, n \geq N \implies |x_m - x_n| < \varepsilon\). Terms eventually get arbitrarily close to each other — without reference to a limit.

Theorem (Cauchy criterion). In \(\mathbb{R}\), a sequence converges if and only if it is Cauchy.

The forward direction (convergent ⟹ Cauchy) uses triangle inequality. The reverse (Cauchy ⟹ convergent) is a deep property of \(\mathbb{R}\) — it fails in \(\mathbb{Q}\) (Cauchy sequence \(1, 1.4, 1.41, 1.414, \ldots\) rationally approximating \(\sqrt{2}\) has no rational limit).

Why it matters. To prove a sequence converges, we do not need to guess the limit. Just show it is Cauchy — then the limit exists by completeness. This is how Itô integrals are constructed: define the integral for simple processes, show the extension is Cauchy in \(L^2\), and conclude the limit (the general Itô integral) exists.

Sequential characterization of limits (bonus). \(\lim_{x \to a} f(x) = L\) if and only if for every sequence \(x_n \to a\) (with \(x_n \neq a\)), we have \(f(x_n) \to L\). This ties limits of functions to limits of sequences and is often easier to use in proofs.

Deeper dive — geometry of ε-δ

Picture the graph of \(f\). The claim \(\lim_{x \to a} f(x) = L\) means: draw a horizontal band of half-width \(\varepsilon\) around \(y = L\); we can always find a vertical strip of half-width \(\delta\) around \(x = a\) (excluding \(a\) itself) so that the graph inside the strip lies inside the band.

The challenge is that \(\varepsilon\) is chosen after \(\delta\) — for any width \(\varepsilon\), no matter how tiny, there must be a corresponding \(\delta\). If someone picks \(\varepsilon = 10^{-100}\), we must still produce a working \(\delta\).

The order of quantifiers matters: "\(\forall \varepsilon, \exists \delta\)" is different from "\(\exists \delta, \forall \varepsilon\)". The second would be a much stronger (usually impossible) statement.

3. Limit laws and evaluation techniques

Proving every limit from scratch with ε-δ would be exhausting. Fortunately, limits obey algebraic laws that reduce complex limits to simple ones.

Theorem 3.1 — Limit laws

Suppose \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\) (both exist). Then:

  • Sum: \(\lim_{x \to a} [f(x) + g(x)] = L + M\)
  • Difference: \(\lim_{x \to a} [f(x) - g(x)] = L - M\)
  • Product: \(\lim_{x \to a} [f(x) g(x)] = L \cdot M\)
  • Quotient: \(\lim_{x \to a} \dfrac{f(x)}{g(x)} = \dfrac{L}{M}\), provided \(M \neq 0\)
  • Constant multiple: \(\lim_{x \to a} [c \cdot f(x)] = c L\)
  • Power: \(\lim_{x \to a} [f(x)]^n = L^n\) for positive integer \(n\)

These are proved from the ε-δ definition using triangle inequality manipulations. See any analysis textbook (e.g., Rudin Ch 4) for full proofs.

Continuous functions behave nicely

For any polynomial \(P(x)\), \(\lim_{x \to a} P(x) = P(a)\) — just substitute. Same for rational functions \(P(x)/Q(x)\) where \(Q(a) \neq 0\). Same for exponential, logarithm, sine, cosine at any point in their domain.

This "just plug in" behavior is exactly the property called continuity, which we define formally in §5.

Indeterminate forms

When "plug in" gives \(0/0\), \(\infty/\infty\), \(0 \cdot \infty\), \(\infty - \infty\), \(0^0\), \(\infty^0\), or \(1^\infty\), the limit's value is not determined by the form — it depends on how the pieces approach their limiting values. These are called indeterminate forms. Techniques to resolve them:

Technique 1 — Factor and cancel

\(\displaystyle \lim_{x \to 2} \frac{x^2 - 4}{x - 2}\) gives \(0/0\).

Factor: \(\dfrac{x^2 - 4}{x - 2} = \dfrac{(x-2)(x+2)}{x - 2} = x + 2\) for \(x \neq 2\).

Limit: \(\lim_{x \to 2} (x + 2) = 4\).

Technique 2 — Rationalize

\(\displaystyle \lim_{x \to 0} \frac{\sqrt{x+1} - 1}{x}\) gives \(0/0\).

Multiply top and bottom by \(\sqrt{x+1} + 1\):

\[ \frac{(\sqrt{x+1} - 1)(\sqrt{x+1} + 1)}{x(\sqrt{x+1}+1)} = \frac{(x+1) - 1}{x(\sqrt{x+1}+1)} = \frac{1}{\sqrt{x+1}+1}. \]

Limit: \(\dfrac{1}{\sqrt{1} + 1} = \dfrac{1}{2}\).

Theorem 3.2 — Squeeze Theorem

Suppose \(g(x) \leq f(x) \leq h(x)\) for all \(x\) near \(a\) (except possibly at \(a\)), and \(\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L\). Then

\[ \lim_{x \to a} f(x) = L. \]
Squeeze in action

\(\displaystyle \lim_{x \to 0} x^2 \sin(1/x) = ?\)

\(\sin(1/x)\) oscillates wildly as \(x \to 0\), but is bounded: \(-1 \leq \sin(1/x) \leq 1\). Multiplying by \(x^2 \geq 0\):

\[ -x^2 \leq x^2 \sin(1/x) \leq x^2. \]

Both \(-x^2 \to 0\) and \(x^2 \to 0\) as \(x \to 0\), so by squeeze theorem the middle expression also \(\to 0\).

4. Limits at infinity and asymptotic behavior

Beyond limits at finite points, we care how a function behaves as \(x\) grows without bound.

Definition 4.1 — Limit at infinity

\(\lim_{x \to \infty} f(x) = L\) means: for every \(\varepsilon > 0\), there exists \(N\) such that \(x > N \implies |f(x) - L| < \varepsilon\).

Analogous definition for \(x \to -\infty\).

Examples:

  • \(\lim_{x \to \infty} \dfrac{1}{x} = 0\)
  • \(\lim_{x \to \infty} e^{-x} = 0\)
  • \(\lim_{x \to \infty} \arctan(x) = \pi/2\)

When a limit at infinity exists, we say \(f\) has a horizontal asymptote \(y = L\).

Growth hierarchy

As \(x \to \infty\), common functions grow at different rates:

\[ 1 \ll \log x \ll x^p \; (p>0) \ll a^x \; (a>1) \ll x^x \]

Here \(f \ll g\) means \(f/g \to 0\), i.e., \(f = o(g)\). Concretely: logarithm grows slower than any positive power of \(x\); exponentials outpace any polynomial.

Comparing growth

\(\displaystyle \lim_{x \to \infty} \frac{x^3}{e^x} = 0\) — exponential dominates cubic.

\(\displaystyle \lim_{x \to \infty} \frac{\ln x}{x} = 0\) — polynomial dominates logarithm.

\(\displaystyle \lim_{x \to \infty} \frac{2x^3 - x + 1}{5x^3 + 7} = \frac{2}{5}\) — same-degree polynomials give ratio of leading coefficients.

Infinite limits

Sometimes \(f(x)\) grows without bound. We write \(\lim_{x \to a} f(x) = \infty\) if for every \(M\), there exists \(\delta\) such that \(0 < |x-a| < \delta \implies f(x) > M\). This is a "limit does not exist" statement in the finite sense but captures the behavior.

Example: \(\lim_{x \to 0^+} 1/x = \infty\), \(\lim_{x \to 0^-} 1/x = -\infty\), so \(\lim_{x \to 0} 1/x\) does not exist. The graph has a vertical asymptote at \(x = 0\).

5. Continuity

Definition 5.1 — Continuity at a point

A function \(f\) is continuous at \(a\) if all three conditions hold:

  1. \(f(a)\) is defined.
  2. \(\lim_{x \to a} f(x)\) exists.
  3. \(\lim_{x \to a} f(x) = f(a)\).

\(f\) is continuous on an interval if it is continuous at every point in the interval.

Continuity captures the intuition "no jumps, no gaps, no vertical asymptotes". Formally, small changes in input produce small changes in output.

Types of discontinuities

When \(f\) fails to be continuous at \(a\), the failure can take several forms:

TypeDescriptionExample
RemovableLimit exists but \(f(a)\) is undefined or wrong\(f(x) = \frac{x^2-1}{x-1}\) at \(x=1\)
JumpLeft and right limits exist but differ\(\text{sgn}(x)\) at \(x=0\)
Essential (infinite)Limit is \(\pm\infty\) or oscillates\(1/x\) at \(x=0\); \(\sin(1/x)\) at \(x=0\)
Theorem 5.2 — Continuity of arithmetic combinations

If \(f\) and \(g\) are continuous at \(a\), then \(f+g\), \(f-g\), \(fg\) are continuous at \(a\). If also \(g(a) \neq 0\), then \(f/g\) is continuous at \(a\).

Theorem 5.3 — Continuity of composition

If \(g\) is continuous at \(a\) and \(f\) is continuous at \(g(a)\), then \(f \circ g\) is continuous at \(a\).

Consequence. Polynomials, rational functions (on their domain), \(e^x\), \(\ln x\), \(\sin x\), \(\cos x\), \(\sqrt{x}\) are all continuous on their domains. Any function built from these by sum, product, quotient, or composition is continuous on the appropriate set.

6. The Intermediate Value Theorem

Theorem 6.1 — Intermediate Value Theorem (IVT)

Suppose \(f\) is continuous on the closed interval \([a, b]\), and let \(y_0\) be any value between \(f(a)\) and \(f(b)\). Then there exists \(c \in [a, b]\) such that \(f(c) = y_0\).

Geometrically: the graph of a continuous function on \([a, b]\) has no jumps, so it takes every value between \(f(a)\) and \(f(b)\).

A continuous curve joining \((a, f(a))\) and \((b, f(b))\) must cross every horizontal line \(y = y_0\) between them, at some \(c\).
What IVT does and doesn't give

Does give: existence of a \(c\) with \(f(c) = y_0\).

Doesn't give: the value of \(c\), uniqueness of \(c\), or a formula. There may be many such \(c\).

Application: root existence

Setting \(y_0 = 0\) gives a powerful tool: if \(f\) is continuous on \([a, b]\) with \(f(a) < 0 < f(b)\), then \(f\) has at least one root in \((a, b)\).

Example — implied yield of a bond

The price of a zero-coupon bond is \(P(r) = 100 e^{-rT}\). Given a market price \(P^* = 78.66\) and maturity \(T = 5\), the yield satisfies \(P(r) - P^* = 0\). Consider \(g(r) = 100 e^{-5r} - 78.66\).

\(g(0) = 100 - 78.66 = 21.34 > 0\); \(g(0.10) = 100 e^{-0.5} - 78.66 \approx 60.65 - 78.66 = -18.01 < 0\). \(g\) is continuous. By IVT, a yield \(r^* \in (0, 0.10)\) exists.

The bisection method in the Code Corner (§8) uses this idea repeatedly to narrow down \(r^*\).

7. Uniform continuity

Ordinary continuity is a pointwise property: for each \(a\) and each \(\varepsilon\), a suitable \(\delta\) exists — but \(\delta\) may depend on both \(a\) and \(\varepsilon\). Uniform continuity demands a single \(\delta\) that works for every point.

Definition 7.1 — Uniform continuity

\(f\) is uniformly continuous on a set \(S\) if for every \(\varepsilon > 0\), there exists \(\delta > 0\) (depending only on \(\varepsilon\), not on the point) such that

\[ x, y \in S, \; |x - y| < \delta \implies |f(x) - f(y)| < \varepsilon. \]
Continuous but not uniformly continuous

\(f(x) = 1/x\) on \((0, 1]\). It is continuous at every point, but near \(x = 0\) the function is very steep — a tiny change in \(x\) produces a huge change in \(f(x)\). No single \(\delta\) works for all points; smaller \(x\) requires smaller \(\delta\). Hence not uniformly continuous on \((0, 1]\).

\(f(x) = x^2\) on \(\mathbb{R}\). Continuous everywhere, but for large \(x\) the slope grows; near \(x = 10^6\), moving even slightly changes \(f\) by a huge amount. Not uniformly continuous on \(\mathbb{R}\).

Theorem 7.2 — Heine-Cantor

If \(f\) is continuous on a closed and bounded interval \([a, b]\), then \(f\) is uniformly continuous on \([a, b]\).

The key restriction is compactness (closed and bounded in \(\mathbb{R}\)). Continuous \(1/x\) on \((0, 1]\) fails because the interval isn't closed; continuous \(x^2\) on \(\mathbb{R}\) fails because \(\mathbb{R}\) is not bounded.

Uniform continuity is a technical strengthening rarely emphasized in introductory calculus, but it becomes essential in integration theory, Fourier analysis, and Ito calculus (where we work with continuous martingales on bounded time intervals).

Deeper dive — extreme value theorem

A close cousin of Heine-Cantor:

Extreme Value Theorem. If \(f\) is continuous on \([a, b]\), then \(f\) attains both a maximum and a minimum on \([a, b]\).

The proof relies on \([a, b]\) being compact: a continuous image of a compact set is compact (hence closed and bounded), so the maximum is achieved.

Application. In optimization, EVT guarantees that a continuous cost function on a bounded, closed feasible region has a global optimum. This is what lets us talk about "the" minimum variance portfolio on a bounded weight simplex.

8. Lipschitz and Hölder continuity

Between continuity and differentiability lies a spectrum of quantitative regularity conditions. Two of them are essential in stochastic analysis.

Definition 8.1 — Lipschitz continuity

\(f: S \to \mathbb{R}\) is Lipschitz continuous on \(S\) if there exists a constant \(K \geq 0\) such that

\[ |f(x) - f(y)| \leq K |x - y| \quad \text{for all } x, y \in S. \]

The smallest such \(K\) is the Lipschitz constant. If \(f\) is differentiable and \(|f'|\) is bounded by \(K\), then \(f\) is Lipschitz with constant \(K\).

Theorem 8.2 — Lipschitz ⟹ uniformly continuous

If \(f\) is Lipschitz with constant \(K\), then for any \(\varepsilon > 0\) the choice \(\delta = \varepsilon / K\) works uniformly.

Proof

Given \(\varepsilon > 0\), let \(\delta = \varepsilon / K\). If \(|x - y| < \delta\), then \(|f(x) - f(y)| \leq K |x - y| < K \delta = \varepsilon\). This \(\delta\) depends only on \(\varepsilon\), not on the point. Hence uniformly continuous. \(\blacksquare\)

The chain of implications:

\[ \text{Lipschitz} \implies \text{uniformly continuous} \implies \text{continuous} \]

Each strengthening buys quantitative information about how much the output can change per unit change in input.

Examples

\(f(x) = \sin x\): Lipschitz on \(\mathbb{R}\) with \(K = 1\) (since \(|f'(x)| = |\cos x| \leq 1\)).

\(f(x) = x^2\): Lipschitz on any bounded interval \([-M, M]\) with \(K = 2M\), but NOT Lipschitz on all of \(\mathbb{R}\) — slope \(2x\) is unbounded.

\(f(x) = \sqrt{x}\) on \([0, 1]\): NOT Lipschitz (derivative \(1/(2\sqrt{x}) \to \infty\) as \(x \to 0^+\)). Uniformly continuous but not Lipschitz — a weaker regularity.

Definition 8.3 — Hölder continuity

\(f\) is Hölder continuous of exponent \(\alpha \in (0, 1]\) on \(S\) if there exists \(C > 0\) with

\[ |f(x) - f(y)| \leq C |x - y|^\alpha \quad \text{for all } x, y \in S. \]

Special cases: \(\alpha = 1\) is Lipschitz. As \(\alpha\) decreases, the condition weakens (allows more flexibility).

\(\sqrt{x}\) on \([0, 1]\) is Hölder-\(1/2\) but not Lipschitz. This is generic: functions with \(|x|^\alpha\)-type singularities in their derivative are Hölder-\(\alpha\) at that point.

Why Lipschitz matters for stochastic differential equations

Consider the SDE \(dX_t = b(X_t) dt + \sigma(X_t) dW_t\) with initial condition \(X_0 = x_0\).

Theorem (Existence and uniqueness of SDE solutions). If \(b\) and \(\sigma\) are Lipschitz continuous with linear growth, then the SDE has a unique strong solution.

Without Lipschitz continuity, multiple solutions can exist (or none). For example, \(dX_t = \sqrt{|X_t|}\, dt\) with \(X_0 = 0\) admits both \(X_t \equiv 0\) and \(X_t = t^2/4\) — non-uniqueness because \(\sqrt{|x|}\) is only Hölder-\(1/2\) at 0, not Lipschitz.

Every well-posed SDE in Track C (Stochastic Processes) requires this hypothesis. This is where §8 pays off.

Deeper dive — Hölder regularity of Brownian motion

Brownian motion paths \(t \mapsto W_t(\omega)\) are almost surely continuous. But how continuous?

Theorem (path regularity). Brownian motion paths are Hölder continuous of exponent \(\alpha\) for every \(\alpha < 1/2\), but are NOT Hölder continuous of exponent \(1/2\).

This precise regularity level (\(\alpha \to 1/2\) but not achieving it) is characteristic of the Wiener process and explains many of its quirks: paths are continuous, but "just barely" — they have infinite bounded variation (§9) and are nowhere differentiable.

This regularity underlies why we need Itô calculus, not classical calculus, to integrate against \(dW\).

9. Bounded variation and a preview of stochastic integration

Continuity tells us a function has no jumps. But continuity alone allows very wild behavior. A stronger regularity, bounded variation, is prerequisite for classical integration and its failure defines the divide between Riemann-Stieltjes and Itô integrals.

Definition 9.1 — Total variation

For a function \(f\) on \([a, b]\) and a partition \(P = \{a = t_0 < t_1 < \cdots < t_n = b\}\), define

\[ V(f, P) = \sum_{i=1}^{n} |f(t_i) - f(t_{i-1})|. \]

The total variation of \(f\) on \([a, b]\) is

\[ V_a^b(f) = \sup_{P} V(f, P), \]

the supremum taken over all partitions. \(f\) is of bounded variation (BV) on \([a, b]\) if \(V_a^b(f) < \infty\).

Intuitively, total variation measures the "total distance traveled" by \(f\) — how much the graph goes up and down cumulatively.

Examples

Monotone functions: any monotone \(f\) has \(V_a^b(f) = |f(b) - f(a)|\), finite. Bounded variation.

Differentiable with bounded derivative: if \(|f'| \leq K\), then \(V_a^b(f) \leq K(b-a)\), finite.

Continuous but wildly oscillating: \(f(x) = x \sin(1/x)\) for \(x > 0\), \(f(0) = 0\). Continuous on \([0, 1]\), but total variation is INFINITE. Bounded variation fails.

Brownian motion: continuous but NOT of bounded variation

Theorem. Almost every Brownian motion path \(t \mapsto W_t\) has infinite total variation on any interval \([0, T]\), \(T > 0\).

Sketch: on a partition with mesh \(\Delta t\), the sum \(\sum |W_{t_i} - W_{t_{i-1}}|\) grows like \(\sqrt{n}\) times the standard deviation of a single increment, which is \(\sqrt{\Delta t}\). Total sum is on the order of \(\sqrt{n \cdot \Delta t} \cdot \sqrt{n} = \sqrt{n} \cdot \sqrt{T}\), which \(\to \infty\) as \(n \to \infty\).

Quadratic variation is finite. By contrast, \(\sum (W_{t_i} - W_{t_{i-1}})^2 \to T\) (in \(L^2\)) as the mesh shrinks. This is the famous \([W, W]_t = t\), the cornerstone of Itô calculus.

Why this matters for integration

Riemann-Stieltjes integral \(\int f\, dg\) is well-defined when \(g\) has bounded variation and \(f\) is continuous. This covers all "classical" integration.

Itô integral \(\int f\, dW\) is required when integrating against processes of infinite variation but finite quadratic variation (like Brownian motion). Requires a completely different construction (limits in \(L^2\) using isometry), not Riemann sums.

This is why stochastic calculus is its own subject and not just "calculus with random noise." The very definition of the integral changes.

Sections §7-§9 together prepare you for Track C (Stochastic Processes). When you meet Brownian motion, you will already know exactly which classical property fails (bounded variation), which one holds (continuity), and what stronger property emerges (finite quadratic variation).

10. Bridge to derivatives

Every derivative is a limit. The definition, which we will develop fully in Lesson 3:

\[ f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}, \]

captures the instantaneous rate of change. The fraction inside is the slope of a secant line joining \((a, f(a))\) and \((a+h, f(a+h))\); the limit as \(h \to 0\) is the slope of the tangent line — provided the limit exists.

Theorem 8.1 — Differentiability implies continuity

If \(f\) is differentiable at \(a\) (i.e., \(f'(a)\) exists), then \(f\) is continuous at \(a\).

Proof

Write \(f(x) - f(a) = \dfrac{f(x) - f(a)}{x - a} \cdot (x - a)\) for \(x \neq a\).

Take limits as \(x \to a\). The first factor \(\to f'(a)\) (by differentiability), the second \(\to 0\). Product law gives

\[ \lim_{x \to a} [f(x) - f(a)] = f'(a) \cdot 0 = 0, \]

which is \(\lim_{x \to a} f(x) = f(a)\), the definition of continuity. \(\blacksquare\)

The converse is FALSE

Continuity does not imply differentiability. Example: \(|x|\) is continuous at \(0\) but has a corner there — the left and right slopes disagree (\(-1\) vs \(+1\)), so \(f'(0)\) does not exist.

More strikingly, the Weierstrass function is continuous everywhere but differentiable nowhere. Brownian motion paths share this property (foundational for stochastic calculus, Lesson later in Track C).

Code corner — bisection method for implied yield

IVT (§6) guarantees a root exists between sign changes. The bisection method locates it by repeatedly halving the interval.

Algorithm — pseudocode:

Bisection root-finder for \(g(r) = 0\)
ALGORITHM Bisection(g, lo, hi, tol) Precondition: g continuous, g(lo) and g(hi) have opposite signs Postcondition: returns r with |r - true root| < tol while (hi - lo) > tol: mid ← (lo + hi) / 2 if g(mid) = 0: return mid if sign(g(mid)) = sign(g(lo)): lo ← mid # root is in [mid, hi] else: hi ← mid # root is in [lo, mid] return (lo + hi) / 2

Each iteration halves the search interval, so after \(n\) steps the error is bounded by \((\text{hi}_0 - \text{lo}_0) / 2^n\). Reliable but slow (linear convergence in bits).

Python implementation:

Python — implied bond yield via bisection
import math def bisection(g, lo, hi, tol=1e-8, max_iter=100): """Find root of g in [lo, hi]. Requires g(lo)*g(hi) < 0.""" if g(lo) * g(hi) > 0: raise ValueError("g must change sign over [lo, hi]") for _ in range(max_iter): mid = 0.5 * (lo + hi) if hi - lo < tol: return mid if g(mid) == 0: return mid if g(lo) * g(mid) < 0: hi = mid else: lo = mid return 0.5 * (lo + hi) # Implied yield of a 5-year zero-coupon bond priced at 78.66 face, price, T = 100.0, 78.66, 5.0 g = lambda r: face * math.exp(-r * T) - price r_implied = bisection(g, 0.0, 0.5) print(f"Implied yield: {r_implied:.4%}") # -> ~4.80% # Sanity check with closed form (from Lesson 1) r_closed = math.log(face / price) / T print(f"Closed form: {r_closed:.4%}")

Comparison with Newton's method (from L1 Code Corner). Newton is quadratic convergence, faster, but requires derivative and can fail to converge without a good starting point. Bisection needs only continuity and a sign-changing bracket — always converges, if slowly. Use bisection when robustness matters more than speed.

🔍 Worked Examples

Example 1 — Factor-and-cancel indeterminate form

Compute \(\displaystyle \lim_{x \to 3} \frac{x^2 - 5x + 6}{x - 3}\).

Direct substitution gives \(0/0\). Factor the numerator: \(x^2 - 5x + 6 = (x-3)(x-2)\).

For \(x \neq 3\): \(\dfrac{(x-3)(x-2)}{x-3} = x - 2\).

Limit: \(\lim_{x \to 3} (x - 2) = 1\).

Example 2 — Prove a limit using ε-δ

Show \(\lim_{x \to 4} \sqrt{x} = 2\) using the ε-δ definition.

Given \(\varepsilon > 0\), we find \(\delta > 0\) so \(|x-4| < \delta\) forces \(|\sqrt{x} - 2| < \varepsilon\).

Rationalize:

\[ |\sqrt{x} - 2| = \left| \frac{(\sqrt{x} - 2)(\sqrt{x}+2)}{\sqrt{x}+2} \right| = \frac{|x - 4|}{\sqrt{x} + 2}. \]

If \(|x - 4| < 1\), then \(3 < x < 5\), so \(\sqrt{x} + 2 > \sqrt{3} + 2 > 3\).

Hence \(|\sqrt{x} - 2| < |x-4| / 3\). To make this \(< \varepsilon\), require \(|x - 4| < 3\varepsilon\).

Choose \(\delta = \min(1, 3\varepsilon)\). Then \(|x - 4| < \delta\) implies both bounds, giving \(|\sqrt{x} - 2| < \varepsilon\). \(\blacksquare\)

Example 3 — Continuity of a piecewise function

For what value of \(k\) is \(f(x) = \begin{cases} x^2 + 1 & x \leq 2 \\ kx + 3 & x > 2 \end{cases}\) continuous at \(x = 2\)?

Left limit: \(\lim_{x \to 2^-} f(x) = 2^2 + 1 = 5\).

Right limit: \(\lim_{x \to 2^+} f(x) = 2k + 3\).

Also \(f(2) = 5\) (from the top piece).

Continuity requires all three equal: \(5 = 2k + 3\), giving \(\boxed{k = 1}\).

Example 4 — Applying IVT

Show that \(f(x) = x^3 + x - 1\) has a root in \((0, 1)\).

\(f\) is a polynomial, hence continuous everywhere, including on \([0, 1]\).

\(f(0) = -1 < 0\) and \(f(1) = 1 + 1 - 1 = 1 > 0\).

By IVT with \(y_0 = 0\), there exists \(c \in (0, 1)\) with \(f(c) = 0\). \(\blacksquare\)

Numerically, bisection converges to \(c \approx 0.6823\).

Example 5 — Squeeze theorem

Compute \(\displaystyle \lim_{x \to \infty} \frac{\sin x}{x}\).

\(\sin x\) oscillates in \([-1, 1]\), so \(-\dfrac{1}{x} \leq \dfrac{\sin x}{x} \leq \dfrac{1}{x}\) for \(x > 0\).

Both bounds tend to \(0\) as \(x \to \infty\), so by squeeze theorem \(\dfrac{\sin x}{x} \to 0\).

Note: this is different from \(\lim_{x \to 0} \dfrac{\sin x}{x} = 1\), a famous limit proved with a geometric argument (see any calculus text or 3Blue1Brown).

✨ Homework — 5 problems

Problem 1
Computation

Evaluate several limits

Compute each. Justify indeterminate cases with a technique.

  1. \(\displaystyle \lim_{x \to 4} \frac{x - 4}{\sqrt{x} - 2}\)
  2. \(\displaystyle \lim_{x \to 0} \frac{\sqrt{1 + x} - \sqrt{1 - x}}{x}\)
  3. \(\displaystyle \lim_{x \to \infty} (\sqrt{x^2 + x} - x)\)
  4. \(\displaystyle \lim_{x \to 0^+} x \ln x\)

(1) Rationalize denominator: \((x-4)/(\sqrt{x}-2) = (x-4)(\sqrt{x}+2)/(x-4) = \sqrt{x}+2\). Limit = 4.

(2) Rationalize numerator: numerator becomes \(((1+x) - (1-x))/(\sqrt{1+x}+\sqrt{1-x}) = 2x/(\sqrt{1+x}+\sqrt{1-x})\). Divide by x: \(2/(\sqrt{1+x}+\sqrt{1-x}) \to 2/(1+1) = 1\).

(3) ∞−∞ form. Multiply by conjugate: \((\sqrt{x^2+x} - x) \cdot \frac{\sqrt{x^2+x}+x}{\sqrt{x^2+x}+x} = \frac{x}{\sqrt{x^2+x}+x} = \frac{1}{\sqrt{1+1/x}+1} \to \frac{1}{1+1} = 1/2\).

(4) 0·(−∞) form. Rewrite as \(\ln x / (1/x)\); apply L'Hôpital (or use growth hierarchy): \(\ln x / (1/x) = -x \ln x \cdot (-1)\)... use substitution \(y = 1/x\), \(y \to \infty\): \(x \ln x = (1/y) \ln(1/y) = -\ln y / y \to 0\). Answer 0.

Problem 2
ε-δ proof

Prove a limit rigorously

Use the ε-δ definition to prove \(\displaystyle \lim_{x \to 2} x^2 = 4\).

Given ε > 0. \(|x^2 - 4| = |x-2||x+2|\).

Restrict \(|x - 2| < 1\), so \(1 < x < 3\) and \(|x + 2| < 5\).

Then \(|x^2 - 4| < 5|x - 2|\). To make this \(< \varepsilon\), need \(|x-2| < \varepsilon/5\).

Choose \(\delta = \min(1, \varepsilon/5)\). Then \(0 < |x - 2| < \delta\) gives \(|x^2 - 4| < \varepsilon\). \(\blacksquare\)

Problem 3
Continuity

Find values making a piecewise function continuous

Determine \(a, b\) so that

\[ f(x) = \begin{cases} x^2 & x \leq 1 \\ ax + b & 1 < x < 2 \\ 3x - 4 & x \geq 2 \end{cases} \]

is continuous on all of \(\mathbb{R}\).

Continuity at \(x = 1\): left = \(1^2 = 1\), right = \(a + b\). Need \(a + b = 1\).

Continuity at \(x = 2\): left = \(2a + b\), right = \(3(2) - 4 = 2\). Need \(2a + b = 2\).

Subtract: \(a = 1\), then \(b = 0\).

Answer: \(a = 1, b = 0\), so middle piece is \(f(x) = x\).

Problem 4
IVT

Prove a fixed point exists

Let \(f: [0, 1] \to [0, 1]\) be continuous. Show that there exists \(c \in [0, 1]\) with \(f(c) = c\) (a "fixed point").

Consider \(g(x) = f(x) - x\). \(g\) is continuous on \([0, 1]\) as a difference of continuous functions.

\(g(0) = f(0) - 0 = f(0) \geq 0\) (since \(f(0) \in [0, 1]\)).

\(g(1) = f(1) - 1 \leq 0\) (since \(f(1) \in [0, 1]\)).

If \(g(0) = 0\), take \(c = 0\). If \(g(1) = 0\), take \(c = 1\). Otherwise \(g(0) > 0 > g(1)\); by IVT, some \(c \in (0, 1)\) has \(g(c) = 0\), i.e., \(f(c) = c\). \(\blacksquare\)

Remark: This is the 1-D Brouwer fixed-point theorem. The multi-dimensional version is central to game theory (Nash equilibrium) and general equilibrium in economics.

Problem 5
Finance

Bisection convergence for implied volatility

Suppose a European call has market price \(C_{\text{mkt}} = 5.20\), spot \(S = 100\), strike \(K = 100\), rate \(r = 0.05\), maturity \(T = 0.25\). The Black-Scholes call price as a function of σ is strictly increasing and continuous on \((0, \infty)\).

  1. Explain why bisection must converge to a unique implied volatility.
  2. How many iterations of bisection on an initial bracket \([\sigma_{\text{lo}}, \sigma_{\text{hi}}] = [0.01, 2.0]\) are needed to reach tolerance \(10^{-6}\)?

(1) Let \(g(\sigma) = C_{\text{BS}}(\sigma) - C_{\text{mkt}}\). As \(\sigma \to 0^+\), \(C_{\text{BS}} \to \max(S - Ke^{-rT}, 0)\), and as \(\sigma \to \infty\), \(C_{\text{BS}} \to S\). Both bounds bracket \(C_{\text{mkt}}\) for typical market prices, so \(g\) changes sign. By IVT (continuity + sign change) a root exists. By strict monotonicity, the root is unique.

(2) Initial bracket width \(w_0 = 2.0 - 0.01 = 1.99\). After \(n\) bisections, width is \(w_n = w_0 / 2^n\). Require \(w_0 / 2^n \leq 10^{-6}\).

\[ 2^n \geq w_0 \cdot 10^6 = 1.99 \times 10^6, \] \[ n \geq \log_2(1.99 \times 10^6) \approx 20.9. \]

So \(n = 21\) iterations suffice.

Remark: Newton's method typically converges in 4-6 iterations, an order of magnitude faster. But bisection is guaranteed to converge; Newton can fail near vanishing Vega.

🎨 Recall

§1 Idea of a limit: \(\lim_{x \to a} f(x) = L\) — outputs get arbitrarily close to \(L\) as inputs approach \(a\). Value \(f(a)\) irrelevant. Two-sided limit exists iff both one-sided limits exist and agree.
§2 ε-δ: for every \(\varepsilon > 0\), some \(\delta > 0\) makes \(0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon\). Quantifier order matters. Uniqueness of limit proved via triangle inequality.
§3 Limit laws: sum, product, quotient (\(M \neq 0\)). Squeeze theorem. Indeterminate forms (0/0, ∞/∞, etc.) resolved by factor, rationalize, or growth arguments.
§4 Limits at infinity: horizontal asymptotes. Growth hierarchy: \(1 \ll \log x \ll x^p \ll a^x\). Infinite limits give vertical asymptotes.
§5 Continuity: three conditions. Removable / jump / essential discontinuity classification. Polynomials, rationals (on domain), exp, log, trig, all continuous. Continuity preserved by arithmetic and composition.
§6 IVT: continuous on \([a, b]\), \(y_0\) between \(f(a), f(b)\) ⟹ \(f(c) = y_0\) for some \(c\). Existence only, not uniqueness or formula. Basis for bisection root-finding.
§7 Uniform continuity: single \(\delta\) for all points, not per-point. Heine-Cantor: continuous on compact ⟹ uniformly continuous. Extreme Value Theorem: continuous on \([a,b]\) attains max and min.
§8 Lipschitz & Hölder: \(|f(x)-f(y)| \leq K|x-y|\) (Lipschitz) or \(\leq C|x-y|^\alpha\) (Hölder). Chain: Lipschitz ⟹ uniform ⟹ continuous. SDE existence requires Lipschitz coefficients.
§9 Bounded variation: total variation \(V_a^b(f) = \sup_P \sum|f(t_i)-f(t_{i-1})|\). Brownian motion has infinite variation but finite quadratic variation \([W,W]_t = t\). This is why Itô calculus differs from Riemann-Stieltjes.
§10 Bridge to derivatives: derivative = limit of difference quotient. Differentiable ⟹ continuous, converse fails (\(|x|\) at 0, Weierstrass). Brownian paths are continuous but nowhere differentiable.
